# 智慧树学习助手 · 个人维护版

这是我基于开源项目整理和维护的智慧树 / 知到课程工具，主要用于自己的课程管理与学习流程辅助。这个版本围绕 Windows 本地使用做了调整，集中整理了启动入口、账号切换、浏览器验证和消息提醒。

## 功能概览

- 支持校内学分课（Hike）与知到共享学分课，可获取课程清单、查看目录，并按课程或视频选择运行范围。
- 提供 Windows 一键启动入口，自动检查 Python 环境和依赖，出错时保留终端提示。
- 支持二维码登录、账号密码登录，以及上次账号的登录状态复用与账号切换。
- 账号密码登录需要验证时打开本机 Chrome 或 Edge，尝试一次自动处理滑块，未通过时可手动完成。
- 学习过程中遇到 `Captcha required` 会暂停并等待验证，每 15 秒重试一次，恢复后继续运行。
- 支持飞书机器人、PushPlus 和 Bark 验证提醒。
- 保留原项目的播放速度、进度阈值、单课时限及 AI 课程相关入口。
- AI 做题支持共享课章节测试、见面课测验及其他普通作业，可导出题目、AI 逐题作答并回读核对，支持一键全做，以及“仅保存 / 保存并提交”两种完成方式。

## 快速开始

需要 Python 3.10 或更新版本。账号密码登录的浏览器验证还需要本机安装 Chrome 或 Edge。

### Windows 启动

将项目解压到本地，双击 `一键启动.bat`，使用方向键 `↑` / `↓` 切换高亮选项，按回车确认。默认选中“账号密码登录”。启动器优先使用项目内的 `venv` 或 `.venv`；没有可用环境时会尝试创建 `.venv`，缺少依赖时会联网安装。

Windows 的全部功能统一由 `一键启动.bat` 提供，项目只保留这一个 BAT。先在首页选择账号密码或扫码登录，登录成功后再选择“自动刷课”或“AI 做题”。两项功能共用本次登录，切换时无需再次登录。首页已移除滑块测试入口。更新后请关闭旧窗口，再重新打开 `一键启动.bat`。

进入功能页前会同时确认课程登录与考试系统登录，并保存通过账号核对的考试会话。旧 Cookie 有时还能读取课程，但已不能为考试系统建立登录；此时会在首页按所选方式重新登录。完成一次登录后，自动刷课和 AI 做题保留各自的业务会话，切换不会覆盖考试登录。若长时间运行后服务端会话过期，请返回登录首页重新登录。

| 首页选项 | 用途 |
| --- | --- |
| 账号密码登录 | 使用上次账号或更换账号，登录后选择功能 |
| 扫码登录 | 使用二维码登录，登录后选择功能 |
| 配置 AI 做题 | 设置做题使用的模型接口、模型名称与隐藏输入的密钥 |
| 配置飞书通知 | 配置飞书机器人的 Webhook 与可选签名密钥 |
| 测试飞书通知 | 向已配置的飞书机器人发送一条测试消息 |
| 退出助手 | 关闭启动器 |

登录后的功能页提供“自动刷课”“AI 做题”“返回登录首页”。自动刷课沿用课程清单、视频范围等设置；AI 做题支持查看未交测试、导出题目、单份或一键全做，并选择仅保存或保存并提交。两项功能结束后均可返回功能选择，返回登录首页后可更换账号。

首页、登录、功能选择、AI 做题和配置页面共用深色面板、蓝色高亮与方向键操作。子菜单中选择返回项并回车，或按 `Esc`，可逐级返回。配置输入中也支持 `Esc` 或输入 `/back` 取消，尚未保存的内容会被丢弃，原配置保持不变。

自动刷课运行页使用同一套深色工作台，集中显示课程与章节、当前视频、播放进度、倍速、运行时间及本课完成 / 已学跳过 / 异常数量，并保留最近动态。视频进度以本次播放目标为分母；达到设置阈值不代表官网整课达到 100%。人机验证期间显示黄色等待状态，验证通过后继续更新；按 `Ctrl+C` 可中止并返回功能选择。终端较小时自动压缩布局；命令行和重定向输出继续使用原有文本模式。

无需登录即可预览运行页：`python study_ui.py`；预览验证等待状态：`python study_ui.py --waiting`（均使用演示数据，不读取账号或发起课程请求）。

只检查环境与 Python 语法，可以在项目目录打开 PowerShell，执行：

```powershell
.\一键启动.bat --check
```

此模式不登录、不发送通知，也不验证线上课程接口是否可用。

### 手动启动

在项目目录中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

后续示例中的 `python` 均指已安装项目依赖的 Python 解释器。使用虚拟环境时，可以将其替换为 `.\.venv\Scripts\python.exe`。

## 登录与账号管理

在一键启动菜单中选中“账号密码登录”或“扫码登录”，按回车使用对应登录方式，再选择要使用的功能。直接运行 `python main.py` 时默认使用二维码登录，也可以指定登录方式：

```powershell
python main.py -q
python main.py --password-login
```

使用账号密码登录时，按提示输入账号和密码，启动器中的密码输入会显示为星号。需要人机验证时，在程序打开的浏览器窗口中完成；只有官网返回验证成功后，程序才继续登录。

登录成功后，程序会在本地保存账号记录。再次启动时，可用方向键 `↑` / `↓` 在“使用上次登录账号登录”“更换账号”和“返回上一级”之间切换，按回车确认，也可按 `Esc` 返回。有效登录状态会被复用，失效后重新登录；更换账号时，新账号登录成功后才替换保存记录。输入账号密码时也可按 `Esc` 或输入 `/back` 取消。

`login_profile.json` 会明文保存账号密码，`cookies.json` 保存登录状态。分享项目时不要包含这些文件，也不要分享填写过凭据的 `config.json`。命令行支持 `-u` / `-p`，但密码可能进入终端历史，日常使用建议按提示输入。

若官网要求短信验证、异地验证或修改密码，请先在官网处理。滑块自动处理仍属于试验功能；真实账号的完整登录流程与线上课程效果需要以实际运行结果为准。

## 课程选择

先获取课程清单：

```powershell
python main.py --fetch
```

程序登录后会将课程名称和 ID 写入 `execution.json`。可以保留需要运行的课程，例如：

```json
[
  { "name": "课程示例一", "id": "123456" },
  { "name": "课程示例二", "id": "789012" }
]
```

每项必须包含 `id`，编辑时保持 JSON 格式正确。未通过 `-c` 指定课程时，程序优先读取这份清单；如果没有指定课程，也没有清单文件，则尝试处理账号下的全部课程。

也可以在命令行中指定范围，示例 ID 需要替换成自己的实际课程和视频 ID：

```powershell
# 指定一门或多门课程
python main.py -c 123456 789012

# 指定一门课程中的视频
python main.py -c 123456 -v 345678

# 将单门课程的运行时限设为 25 分钟
python main.py -c 123456 -l 25

# 指定 AI 课程及班级 ID
python main.py -ai 123456 654321
```

校内学分课的课程 ID 对应页面地址中的 `courseId`，共享学分课对应 `recruitAndCourseId`。视频 ID 根据课程类型使用 `fileId` 或接口返回的 `videoId`。AI 课程的附加设置见自动生成的 `config.json` 中的 `ai` 字段；其中的模型配置与密钥占位值需要按实际服务填写。

## AI 做题

双击 `一键启动.bat`，在首页登录后选择“AI 做题”，再用方向键选择课程（例如“跨文化英语”），再选择查看未交测试列表、拉取题目或 AI 自动答题。列表用 `[章节测试]`、`[见面课]`、`[其他作业]` 等标记区分类型。在测试选择页可以选择单份测试，或“一键全做（全部作业）”。开始前选择“仅保存（不交卷）”或“保存并提交（核对成功后交卷）”，默认选中仅保存。

一键全做按当前课程的未交列表顺序处理章节测试、见面课测验与其他普通作业。没有章节标识或见面课标记的作业（例如 `test`）同样支持单份导出、单份作答和批量作答，不再按分类直接跳过；实际依据试卷题型处理。目前自动保存支持纯文字单选、多选与判断题。互评使用独立流程，以及包含尚不支持题型的试卷，会明确显示未处理原因；有跳过项时，结果标题标明“有未完成作业”。网络、模型或提交状态不确定等错误会停止批量流程，列出未运行数量。已有服务器答案仍然保留。

官网提示见面课测验提交后不可重做，建议先选择仅保存，在官网核对答案后再决定是否提交。期末在线考试不在此功能范围内；未开放的测试仍需等待官网开放。本次见面课适配已核对官网公开脚本并完成离线回归，尚未用真实见面课试卷验证保存或交卷。

所有结果页提供“返回上一页”。单份测试或批量处理完成后返回测试选择页，可继续选下一份；选择完成方式时按 Esc 也返回测试选择页。之后按 Esc 可逐级返回做题操作、课程列表、功能选择。查看未交列表的结果页则返回做题操作。返回后保留本次登录，可继续切换自动刷课或 AI 做题。长菜单随方向键滚动，结果列表和完整文件路径按终端高度分页显示。飞书配置、飞书测试和 AI 配置返回后，也可以继续使用首页。

命令行也可直接指定范围：

```powershell
# 列出一门共享课的未交测试；课程ID为 recruitAndCourseId
python main.py --chapter-tests list -c 课程ID

# 导出一份测试题目；测试ID使用上一步显示的 id
python main.py --chapter-tests export -c 课程ID --chapter-exam 测试ID

# AI 自动作答，每题保存成功后回读核对，再处理下一题
python main.py --chapter-tests answer -c 课程ID --chapter-exam 测试ID

# 同一课程一键全做，仅保存
python main.py --chapter-tests answer -c 课程ID --chapter-all

# 同一课程一键全做，每份测试核对完成后交卷
python main.py --chapter-tests answer -c 课程ID --chapter-all --chapter-submit

# 仅检查本地环境，不登录、不读取测试、不保存答案
.\一键启动.bat --check
```

自动作答复用 `config.json` 的 `ai` 配置。从 `一键启动.bat` 的主菜单进入“配置 AI 做题”，可在统一的三步面板中设置接口、模型及隐藏输入的密钥。已有配置会保留，接口未变时密钥留空可沿用；按 Esc 可取消。可使用 DeepSeek 官方地址 `https://api.deepseek.com` 和模型名 `deepseek-v4-flash`；保存后启用外部模型，不改变账号、通知等其他配置。DeepSeek 官方目前将该兼容模型名路由到最新的 Flash 模型，详见[官方更新说明](https://api-docs.deepseek.com/updates/)。原图形配置窗口仍可用 `python chapter_ai_settings.py --gui` 单独打开。

手动配置时，`enabled` 开启后，`use_zhidao_ai=true` 使用原有知到 AI；设为 `false` 时需填写有效的 `openai.api_base`、`api_key` 和 `model_name`。接口地址可含 `/v1`，程序会避免重复拼接。模型回答会校验选项 ID；模型失败或答案格式错误时停止，不随机填答案。密钥保存在本机 `config.json`，不要分享此文件。

当前支持纯文字单选、多选和判断题。图片、音视频、附件和其他题型会导出，但遇到尚未作答的此类题目时自动流程停止，需要人工处理。已有服务器答案默认保留；重新运行时从服务器尚未作答的题目继续。网络超时、验证码、锁定、保存拒绝或回读不一致都会停止当前流程，避免把不确定的结果标记成成功。

题目与逐题状态写入 `chapter_test_data/`，按账号和试卷标识的哈希分目录，批量结果保存为`batch-progress.json`，均已加入忽略列表。“仅保存”不会调用交卷接口；“保存并提交”会在全部答案再次回读一致后提交，随后读取试卷状态，只有服务器状态为已提交或已结束才显示提交完成。请求超时或状态未确认时不会自动重复交卷，需到官网核对；保存成功不代表答案评分正确。测试接口会用当前账号的 Cookie 完成官网考试系统的会话跳转，切换功能时不再要求重复输入账号。若官网登录已失效，仍需返回首页重新登录。

协议依据为 2026-10-20 取得的官网公开脚本。已在线确认动态密钥获取，并完成“跨文化英语”的登录、12项未交测试/作业列表读取（其中11份章节测试）及绪论测试1道题目的拉取。知到内置 AI 在联调时返回业务错误509，改用用户本地配置的DeepSeek后，绪论测试1道题已完成真实AI生成、保存和服务器回读核对；未交卷、未取得评分，其余章节尚未运行。离线回归共96项通过。详细验证范围见 [章节测试开发说明](docs/chapter-tests-protocol.md)。

## 验证等待与消息提醒

运行中遇到 `Captcha required` 时，程序会提示前往智慧树官方学习页面或手机端完成验证。等待期间不累计播放进度，每 15 秒重试一次，接口恢复正常后继续；按 `Ctrl+C` 可以结束等待。

每次进入验证等待时发送一次提醒，持续等待期间不重复推送。恢复后再次遇到验证会重新提醒，通知发送失败不会结束主程序。

### 飞书通知

1. 在接收提醒的飞书群中添加自定义机器人，复制 Webhook 地址。
2. 双击 `一键启动.bat`，用方向键选中“配置飞书通知”并按回车，再选“开始配置”。按提示填写地址；启用了签名校验时，再填写签名密钥。中途可按 `Esc` 取消，未完成填写不会保存。
3. 如果机器人启用了关键词校验，可将关键词设为“智慧树”。
4. 在结果页选择“返回上一级”，再进入“测试飞书通知”。选择“发送测试通知”后才会发送消息，随后查看结果页并确认机器人所在群收到消息。
5. 返回菜单选中账号密码登录或扫码登录，按回车启动主程序。已运行的主程序需要重启，使通知设置生效。

通知包含提醒时间和验证处理说明，不包含账号密码、Cookie 或登录凭据。接口接受通知后，手机是否弹出提醒仍取决于飞书通知设置和群静音状态。

单独检查飞书配置格式：

```powershell
python notification_settings.py --check
```

该命令不发送测试消息。PushPlus 和 Bark 可在 `config.json` 中启用并填写各自的 Token。

## 配置说明

首次运行 `main.py` 时会自动生成 `config.json`。建议在生成的文件中修改需要的字段，保留其余设置。

| 字段 | 说明 |
| --- | --- |
| `username` / `password` | 可选的账号密码配置 |
| `qrlogin` | 默认 `true`，使用二维码登录；`--password-login` 可切换为账号密码登录 |
| `save_cookies` | 是否保存登录状态；账号记录另存于 `login_profile.json` |
| `proxies` | 代理设置，默认空对象 |
| `logLevel` | 日志等级，默认 `INFO` |
| `tree_view` | 是否显示课程目录，默认开启 |
| `progressbar_view` | 是否显示视频进度条，默认开启 |
| `qr_extra.show_in_terminal` | 是否在终端显示二维码；未指定时 Windows 默认开启 |
| `qr_extra.ensure_unicode` | 是否只使用 Unicode 字符输出二维码 |
| `image_path` | 二维码图片保存路径，留空则不保存 |
| `pushplus` / `bark` | 对应通知渠道的启用开关与 Token |
| `feishu` | 飞书通知的 `enable`、`webhook` 与 `secret` |
| `ai` | AI 课程的服务、模型及相关设置 |

## 常用参数

| 参数 | 作用 |
| --- | --- |
| `-c`, `--course` | 指定一个或多个课程 ID |
| `-v`, `--videos` | 指定一个或多个视频 ID |
| `-q`, `--qrlogin` | 使用二维码登录 |
| `--password-login` | 使用账号密码登录，与 `-q` 互斥 |
| `--interactive-menu` | 登录后选择自动刷课或 AI 做题，共用本次会话 |
| `-u`, `--username` | 指定账号 |
| `-p`, `--password` | 指定密码，注意终端历史中的明文记录 |
| `-f`, `--fetch` | 获取课程清单并写入 `execution.json` |
| `-s`, `--speed` | 指定播放速度；未设置时共享课默认 1.5，校内课默认 1.25 |
| `-t`, `--threshold` | 视频完成进度阈值，默认 0.91 |
| `-l`, `--limit` | 单门课程的运行时限，单位为分钟，默认 0 表示不限时 |
| `-d`, `--debug` | 开启调试日志，日志可能包含敏感请求数据 |
| `--proxy` | 设置代理地址 |
| `--show_in_terminal` | 在终端显示二维码 |
| `--image_path` | 设置二维码图片保存路径 |
| `-ai`, `--aicourse` | 指定 AI 课程 ID 和班级 ID |
| `-h`, `--help` | 查看完整参数帮助 |
